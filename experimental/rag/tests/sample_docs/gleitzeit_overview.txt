Gleitzeit Overview

Gleitzeit is a powerful workflow orchestration system designed specifically for LLM (Large Language Model) applications. It provides a unified framework for executing complex workflows that combine LLM interactions, Python code execution, and MCP tool integration.

The system is built on a protocol-based architecture that allows for easy extensibility. Providers implement specific protocols to handle different types of tasks, such as LLM chat completions, code execution, or custom tool operations.

Key features of Gleitzeit include:
- YAML-based workflow definitions for ease of use
- Built-in batch processing capabilities for handling multiple files
- Parameter substitution for chaining task outputs
- Automatic persistence with fallback options (Redis, SQL, Memory)
- Comprehensive error handling with retry logic

The system supports various execution patterns including sequential tasks, parallel execution, and complex dependency graphs. Tasks can reference results from previous tasks using a simple substitution syntax.
